A custom **Personality Module** mod for **!Ω Factorial Omega: My Dystopian Robot Girlfriend (MDRG)** introducing unique behavioral states, dialog lines, and longing/fluid retention tracking.

---

## 🎮 Features

- **Custom Module:** Equippable Personality Module with unique in-game responses.
- **Dynamic Dialogue:** Custom dialogue branches across interactions, headpats, and scenes.
- **State Logic:** Custom internal tracking for fluid retention and satisfaction levels.
- Verified 100% working on MDRG version **v0.97.12** (Target: `0.96.7`).

---

## 📥 Installation

1. Go to the [**Releases**](https://github.com/MDRG-MODS/cxm-queen-pm/releases) page and download `Cum queen.zip`.
2. Navigate to your MDRG installation directory:
   ```text
   .../My Dystopian Robot Girlfriend/FactorialOmega_Data/StreamingAssets/Mods/
   ```
3. Extract `Cum queen.zip` into your `Mods/` directory so that `mod.json` is located at:
   ```text
   .../StreamingAssets/Mods/Cum queen/mod.json
   ```
4. Launch the game and equip the module on your bot.
